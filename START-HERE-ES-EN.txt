ESPAÑOL

Instalación
1. Extrae el ZIP completo en una carpeta permanente.
2. Para actualizar un equipo existente, conserva una copia anterior y reemplaza
   los tres HTML en la misma ubicación y con los mismos nombres. No borres los
   datos del navegador. Usa el mismo navegador y perfil de siempre.
3. Abre index.html y elige MOTIVATED o COTTONBALL.
4. Cada programa abre en su propia pestaña. Vuelve a Label Center para cambiar
   de clínica; una orden pendiente puede permanecer abierta en su pestaña.
5. Prepara y revisa la etiqueta y utiliza Print labels dentro del programa.

Qué cambia
La portada incluye un símbolo oficial nítido, grande y girando lentamente en
una esquina. Los programas incorporan una entrada visual breve del encabezado
y los paneles. Las animaciones respetan la preferencia de reducir movimiento.
No se modifican QR, recetas, tipografía, centrado, tamaños ni impresión.

Datos y acceso
El catálogo y el perfil siguen guardándose en cada navegador y origen. Agregar
un medicamento NO actualiza otras computadoras. La conexión a un catálogo
compartido aún no está implementada. Tampoco se migran datos entre dominios.
Los archivos están preparados para el repositorio existente; la activación de
GitHub Pages sigue pendiente de resolver su visibilidad.

Si solo deseas la portada nueva, reemplaza únicamente index.html. Para tener
las entradas animadas dentro de los programas, utiliza también los dos HTML
incluidos en esta entrega. Mantén las rutas y nombres existentes.

ENGLISH

Installation
1. Extract the entire ZIP into a permanent folder.
2. To update an existing workstation, keep a backup and replace the three HTML
   files at the same paths and with the same names. Do not clear browser data.
   Use the same browser and profile as before.
3. Open index.html and choose MOTIVATED or COTTONBALL.
4. Each program opens in its own tab. Return to Label Center to switch clinics;
   an unfinished order can stay open in its program tab.
5. Prepare and review the label, then use Print labels inside the program.

What changes
The landing page includes a crisp official symbol rotating slowly, partially
outside one corner. Programs add a short header and panel entrance. Animations
respect reduced-motion preferences. QR, formulas, label typeface, centering,
dimensions and printing are unchanged.

Data and access
The catalog and printer profile remain stored per browser and origin. Adding
a medication does NOT update other computers. A shared catalog connection is
not implemented yet. Data is not migrated between domains. Files are prepared
for the existing repository; GitHub Pages activation still depends on its
visibility decision.

Replace only index.html if you only want the new landing page. Install both
application HTML files too for their entrance animations. Preserve filenames
and existing paths.
