Label alignment test

Check the starting position and repeatability of your round labels. Choose a clinic, print the alignment targets, then adjust one dot at a time.

MOTIVATED — TEST COTTONBALL — TEST

These copies use their own saved settings and catalogs. The official programs keep their current settings, rules and links. No automatic alignment correction has been added.

Start with one printer

  1. Keep the current Windows printer settings for the first run. Record the printer, its Top / Left settings and the label size. Use the same roll throughout the comparison.
  2. Open a test copy. Choose Printer & alignment and check the resolution and physical label diameter. For the current 1-inch stock: 300 dpi, 1.00-inch page, 0.95-inch content.
  3. Choose Zero test X / Y, then Print 1 test. In Chrome use the intended Zebra printer, matching paper size, scale 100%, no margins, headers and footers off, and Copies: 1.
  4. If the target is visible, choose Print 10 tests. Keep the strip intact and compare TEST 01 with TEST 10.
  5. If all targets have the same small offset, use Left / Right / Up / Down 1 dot. Print again, then choose Save printer settings when the position is consistent. This saves only the test profile.

Read the result

Same offset on every label: a fixed correction may help. Changing position, skipped labels or only the first label displaced: record the pattern; repeatedly changing X / Y will not fix inconsistent feeding. Keep the strip and send a photo showing several complete labels.

Zero means the center of the page sent by the program. It does not measure the physical sticker. One dot is approximately 0.083 mm at the 300-dpi Zebra setting. Large shifts can clip a label; the existing fit checks remain active.

Windows and the physical printer are still shared. These copies do not change driver settings or run printer calibration. A later test with driver Top / Left at zero needs the working settings recorded and restored, or a dedicated test printer setup.

After the alignment targets

Compare a short name and a long name, and Compound / Fill in Motivated. Check Cottonball VX.5 too. Keep the same profile for all comparisons. After replacing a roll, repeat the targets before a medication batch.

To compare against your exact saved production settings, export the profile from the official program and import it here. Importing fills the test controls; use Save printer settings to keep it. Custom medications are not imported automatically.
