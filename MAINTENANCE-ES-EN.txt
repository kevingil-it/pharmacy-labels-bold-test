LABEL CENTER — MAINTENANCE / MANTENIMIENTO
Portal 1.3 · 2026-11-09

ESPAÑOL

Estructura
index.html contiene estilos, fuentes integradas, marca y dos enlaces nativos.
No ejecuta JavaScript ni usa iframe. Sus botones abren documentos independientes
mediante target="_blank" y rel="noopener". No accede al almacenamiento ni a la
impresora. Los programas conservan su propio código y sus rutas habituales.

Marca y fondo
El símbolo procede de https://www.thepharmacyhub.com/ y del recurso oficial
/assets/mark-navy-P16WB9v1.png (1024 × 1024 RGBA). Se integra como data URL sin
alterar sus píxeles. La versión blanca se obtiene con un filtro CSS, tanto en
.brand-symbol como en .corner-mark. El wordmark central previo se conserva.
.corner-brand determina tamaño, posición y opacidad del símbolo de fondo.
.symbol-orbit es el nombre conceptual del movimiento; el @keyframes real se
llama symbol-orbit y dura 100 segundos. La decoración tiene aria-hidden y no
recibe eventos del puntero. .ambient limita su desbordamiento al viewport.
La preferencia prefers-reduced-motion desactiva todas las animaciones.

Entrada de programas
El único cambio en compound-labels-NEW.html y cottonball-labels.html es el
style con id labelCenterEntrance, antes de </head>. Contiene @media screen and
(prefers-reduced-motion: no-preference). Anima header, los dos section directos
de .grid y footer, de 650 a 750 ms con retrasos de hasta 230 ms. No modifica
tamaños ni posiciones finales. :focus-within evita ocultar controles enfocados.
Retirar ese bloque exacto devuelve cada programa a su original byte por byte.
No cambies media screen por all ni animes #printOnly, SVG o clases de etiqueta.

Añadir una clínica
Valida su HTML de forma independiente. Colócalo con un nombre único y estable
junto a index.html. Duplica .clinic y cambia nombre, href y aria-label. Conserva
la apertura en otra pestaña. Revisa el enlace sin modificar motores existentes.

Catálogo
Las claves de localStorage y la validación siguen iguales. El catálogo no se
comparte automáticamente. Una implementación futura necesita base de datos,
identidad y permisos de escritura por clínica; no pongas credenciales privadas
de GitHub o base de datos en el HTML. Esta entrega no activa sincronización.

Verificación
Verification-Results.json separa la validación histórica de etiquetas de la
revisión visual actual. Se verificaron ambos enlaces y ejemplos en el navegador.
La eliminación del bloque nuevo reproduce los originales y todos los scripts
siguen idénticos. No se realizó prueba física de impresión para este cambio.

ENGLISH

Structure
index.html contains CSS, embedded fonts, branding and two native links. It runs
no JavaScript and uses no iframe. Links open independent documents with
target="_blank" and rel="noopener". It accesses neither storage nor printers.
The applications retain their own code and established paths.

Brand and background
The symbol comes from https://www.thepharmacyhub.com/ and its official asset
/assets/mark-navy-P16WB9v1.png (1024 × 1024 RGBA). Original pixels are embedded
as a data URL. CSS filters display it in white in .brand-symbol and .corner-mark.
The previous centered wordmark is retained. .corner-brand controls the background
symbol’s size, position and opacity. symbol-orbit rotates it over 100 seconds.
Decorations are aria-hidden and do not receive pointer events. .ambient clips
its contents to the viewport. prefers-reduced-motion disables all animations.

Application entrance
The only addition to compound-labels-NEW.html and cottonball-labels.html is the
style element with id labelCenterEntrance before </head>. It is scoped to
@media screen and (prefers-reduced-motion: no-preference). Header, direct .grid
sections and footer animate for 650–750 ms with delays up to 230 ms. Final
positions and dimensions do not change. :focus-within keeps focused controls
visible. Removing that exact block restores the approved original byte for byte.
Do not change screen to all or animate #printOnly, SVGs or label classes.

Adding a clinic
Validate its HTML independently. Place it under a unique, stable name beside
index.html. Duplicate .clinic and update its name, href and aria-label. Keep
new-tab navigation. Check the link without altering existing label engines.

Catalog
localStorage keys and validation are unchanged. Catalogs do not synchronize.
A future shared implementation requires a database, authentication and clinic
write permissions; never embed private GitHub or database credentials in HTML.
This release does not enable synchronization.

Verification
Verification-Results.json separates historical label checks from current UI
review. Both links and reference examples were checked in the browser. Removing
the added CSS reproduces originals and every script remains identical. No
physical printer test was performed for this visual change.
