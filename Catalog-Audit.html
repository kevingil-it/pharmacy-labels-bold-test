The Pharmacy Hub · November 10, 2026 · Release audit

Catalog reconciliation and date validation

Outcome: 32 supplied Cottonball PDFs represent 31 distinct code/variant/formula combinations. Every source PDF is represented. One duplicate option, CX.1 Resistant, has been consolidated. No other duplicate ingredient-and-concentration set was found.

Evidence and scope

The audit decoded every QR directly from all 32 one-page PDFs in the supplied cottonballqrcodes.zip, checked QR error-correction parity, reviewed rendered labels, and compared titles and complete QR payloads with the bundled catalog. All 32 previous payloads matched their source PDFs exactly. Ingredient comparison normalizes decimal formatting, spacing and capitalization; the trailing “-Resistant” is a variant annotation. It does not treat different ingredients or strengths as equivalent.

Motivated’s 18 bundled entries were checked for repeated names and against the pre-change release and the two available uploaded HTML catalogs. None was repeated or missing from those HTML references. No independent set of Motivated formula PDFs was found, so external formula completeness cannot be certified for that clinic. Custom entries saved on individual PCs are outside this inventory.

Why CX.1 Resistant appeared twice

The source archive contains two PDFs for the same variant. Both encode Hydroquinone 8%, Niacinamide 2%, Fluocinolone 0.01%, Kojic Acid 1% and Tretinoin 0.05%. Their QR strings differ in spacing, decimal formatting, capitalization and the suffix “-Resistant”. The earlier import preserved each QR string as a separate menu entry. Removing “PDF” from the visible labels later made both options look identical without removing either entry.

The release retains the existing canonical CX.1 Resistant entry and its exact QR payload from the PDF ending “(12)”. The PDF ending “(2)” remains a documented alternate source for the same ingredient/concentration set. No second recipe is removed.

Existing workstation catalogs

Only the two known, unedited bundled CX.1 entries are consolidated automatically. Password information, custom entries and printer settings remain intact. The removed legacy entry is archived inside the saved catalog record. If only the known legacy entry is present, its name is consolidated while its original QR text is preserved. If either formula has been edited, both entries are retained and the legacy option is marked for review. A failed save leaves the existing catalog in place. Reopening the release does not repeat an already-completed change.

Date rules in both official programs

  • Preparation date and BUD are required and must be valid calendar dates.
  • BUD earlier than preparation is blocked; the dates are never silently swapped.
  • Same-day BUD is allowed. Comparison uses calendar dates, not local timezone conversion.
  • Print, Ctrl+P/Command+P and label SVG/ZPL export use the same validation. Browser-menu printing does not receive an invalid medication label.
  • Alignment test sheets remain independent of medication dates.

These rules detect invalid or reversed dates. They do not establish the approved shelf life, infer whether a valid month/day was entered incorrectly, or impose a new ban on historical reprints or future dates.

Preserved behavior

Label geometry, fonts, QR size and positioning, physical page dimensions, print CSS, printer profile keys and calibration rules remain unchanged. The calibration investigation stays in separate test copies. Software verification is recorded in Catalog-Date-Verification.json; no physical printer test was performed for this update.
